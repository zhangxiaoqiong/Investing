# 研究质量标准

每篇研究先核实事实和基本关系，再判断证据能支持多强的结论。归档时记录研究日期、数据截止日期、版本与来源，确保读者能复查关键数据和推导。

## 证据分级

| 等级 | 判断依据 |
| --- | --- |
| A · 可核实的事实或数学关系 | 能追溯到具体来源、定义或计算过程。数据注明期间、单位和口径。 |
| B · 有证据的推论 | 给出前提、因果机制和适用条件，并考虑其他可能的解释。 |
| C · 待验证的假设 | 写明已有依据、仍缺的证据，以及什么观察结果会支持或推翻它。 |
| D · 依据不足的观点 | 标明不确定性，记录待查问题。 |

分级用于描述证据强弱。历史数据与未来预测分别标注，预测需写明假设、时间范围和来源。

## 归档前检查

- **事实与口径**：优先引用原始披露、统计数据或原始研究。数字核对期间、单位、样本范围和统计口径，区分已实现数据、管理层指引和市场预期。
- **常识与基本规律**：检查数量级、计算、供需、成本和现金流关系，写清适用条件。遇到异常时回查数据和假设。
- **因果与价值分配**：交代推导链和替代解释，说明谁创造价值、谁获得收益、谁承担成本。
- **反证与敏感性**：列出会改变判断的证据。涉及关键变量时，说明主要变量变化对结论的影响。
- **投资判断**：分别检验技术价值、企业盈利、资本回报与市场定价。证据有限时给出条件性判断，并列出下一步要跟踪的变量。
