# Investing

这是长期积累经济、产业、企业、科技与投资认知的个人研究知识库。在 Obsidian 或 GitHub 上，从[研究总索引](00_研究体系/研究总索引.md)进入，或查看[研究方法论](00_研究体系/研究方法论.md)和[研究质量标准](00_研究体系/研究质量标准.md)。

| 目录 | 内容 |
| --- | --- |
| `00_研究体系` | 方法论、质量标准和总索引 |
| `01_每日研究` | 按年份归档的每日研究报告 |
| `02_基础理论` | 第一性原理、价值论、定价理论与价值投资 |
| `03_产业研究` | 产业链、竞争格局和价值分配 |
| `04_商业模式与企业` | 商业模式、企业基本面和资本配置 |
| `05_估值与投资` | 财务、资本回报、估值与市场预期 |
| `06_研究假设与复盘` | 可检验的假设、反证与判断更新 |
| `07_资料与参考文献` | 原始资料、数据出处与参考文献 |

每周聚焦一个研究问题，每日从具体案例或证据推进。归档时记录研究日期、数据截止日期、版本与来源，并在总索引添加链接和一句摘要。
